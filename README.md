      <h3>🚀 Featured Project</h3>
      <p>
        <a href="https://github.com/edilsonvilarinho/usage-monitor"><b>usage-monitor</b></a> — a desktop HUD showing the
        <b>quota, usage and cost of every AI coding tool you pay for</b>: Claude Code, Codex, OpenCode, Gemini CLI, Kilo,
        DeepSeek, MiniMax, OpenRouter and Cursor.
      </p>
      <ul>
        <li>One ring per account, one arc per quota, docked as a notch on the screen edge.</li>
        <li>Reads the credentials you already have — history stays in local SQLite, nothing leaves the machine.</li>
        <li>Also runs from the terminal: status table, status lines for Claude Code and tmux, TUI and a headless service for Linux servers.</li>
        <li>Kotlin Multiplatform + Compose Multiplatform, released for Windows, Linux and macOS.</li>
      </ul>
